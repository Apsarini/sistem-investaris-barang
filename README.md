# Sistem Manajemen Data Interaktif - Inventaris Barang

Proyek Ujian Tengah Semester (UTS) Mata Kuliah **Pemrograman Web 1** (Semester 5) — Universitas Adhirajasa Reswara Sanjaya.

## Fitur Utama
- **HTML5 Semantik**: Menggunakan `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, dan `<footer>`.
- **CSS Modern Mobile-First**: Menggunakan Flexbox dan CSS Grid tanpa framework eksternal.
- **JavaScript Interaktif**: Validasi form *real-time* dan pengalih tema (*Dark/Light Mode*) dengan `localStorage`.
- **Pemrosesan Backend PHP**: Penanganan input data barang dengan metode `POST` (dilengkapi CSRF Token, Validasi Server-Side, & PRG Pattern) dan pencarian/filter dengan metode `GET`.

## Struktur Folder
- `index.php` — Halaman utama dan pemrosesan logika server PHP.
- `style.css` — Styling responsif *mobile-first*.
- `script.js` — Validasi *client-side* dan manipulasi DOM.
- `docs/` — Berisi dokumen laporan proyek (`Laporan Project [Nama Mahasiswa].docx`) dan dokumentasi screenshot.
